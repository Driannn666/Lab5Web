
# Praktikum 5 — JavaScript Dasar

## Tujuan
Memahami dasar JavaScript dan manipulasi elemen HTML.

## Perangkat
- Visual Studio Code
- Browser
- HTML dan JavaScript

## Cara Menjalankan
1. Buka folder proyek di VS Code.
2. Jalankan index.html menggunakan browser.
3. Ikuti pengujian setiap latihan.

## Hasil Praktikum
- Latihan 1: Menampilkan output.
- Latihan 2: Alert dan prompt.
- Latihan 3: Operasi aritmetika.
- Latihan 4: Percabangan if–else.
- Latihan 5: Percabangan switch.
- Latihan 6: Bilangan genap atau ganjil.
- Latihan 7: Mengubah warna halaman.
- Latihan 8: Checkbox menu makanan.
- Mini Project: Kalkulator nilai mahasiswa.
